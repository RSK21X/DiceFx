# DiceFX 1.1.0 — Compact black & yellow / 紧凑黑黄界面

![DiceFX 1.1.0](https://raw.githubusercontent.com/RSK21X/DiceFx/v1.1.0/docs/images/dicefx-main.png)

## English

This release replaces the previous editor with a compact, flat black-and-yellow interface. **The audio-processing code is unchanged.**

- Four effects in a tidy 2×2 panel; default 800 × 500, resizable from 720 × 450 to 1120 × 700.
- Embedded SVG icons, consistent circular knobs and non-overlapping controls.
- Quick access to presets, randomization amount, global input/mix/output, undo/redo and A/B.
- Module locks plus an individual parameter-lock drawer.
- Correct delay and LFO value labels when changing sync mode.
- New illustrated English and Chinese READMEs and a pinned JUCE dependency.

### Downloads

- **VST3 ZIP**: extract and copy `DiceFX.vst3` to `~/Library/Audio/Plug-Ins/VST3/`, then reopen your DAW and rescan.
- **Standalone ZIP**: extract `DiceFX.app` for a preview without a DAW. Audio input starts muted to avoid feedback.
- **SHA256SUMS.txt**: checksums for both archives.

Both bundles include **Apple Silicon and Intel** slices and target **macOS 11+**. They are ad-hoc signed, **not Apple-notarized**. AU, AAX and Windows binaries are not included.

Checks passed on macOS 27, natively on Apple Silicon and for the Intel slice under Rosetta. Older macOS versions and a physical Intel Mac were not runtime-tested.

Validation covers SVG rendering, four editor sizes, knob and control geometry, parameter bindings, presets, locks, randomization, undo/redo, A/B, sync labels, and offline audio processing across all factory presets at 44.1/48/96 kHz with 64/512-sample blocks. See the repository READMEs for build and test commands.

## 中文

本次发布将旧界面替换为紧凑的黑黄扁平界面，**音频处理代码保持不变**。

- 四个效果器以整洁的 2×2 面板呈现；默认 800 × 500，可在 720 × 450 至 1120 × 700 之间缩放。
- 内嵌 SVG 图标、统一的正圆旋钮和不重叠的控件。
- 快速访问预设、随机幅度、全局输入/混合/输出、撤销与重做以及 A/B。
- 支持模块锁和单独参数锁抽屉。
- 切换同步模式时正确更新延迟与 LFO 的数值标签。
- 新增配图中英文 README，并固定 JUCE 依赖版本。

### 下载与安装

- **VST3 压缩包**：解压后将 `DiceFX.vst3` 复制到 `~/Library/Audio/Plug-Ins/VST3/`，重新打开 DAW 并扫描插件。
- **独立应用压缩包**：解压得到 `DiceFX.app`，无需 DAW 即可预览。为避免反馈，音频输入默认静音。
- **SHA256SUMS.txt**：两个压缩包的校验值。

两个发布包均包含 **Apple Silicon 和 Intel** 架构，构建目标为 **macOS 11+**。发布包采用 ad-hoc 签名，**未经过 Apple 公证**。本次不包含 AU、AAX 或 Windows 安装包。

检查已在 macOS 27 上通过 Apple Silicon 原生运行及 Rosetta 下的 Intel 架构运行。未对较旧的 macOS 版本及实体 Intel Mac 进行运行验证。

验证包含 SVG 渲染、四种窗口尺寸、旋钮与控件几何、参数绑定、预设、参数锁、随机化、撤销与重做、A/B、同步数值，以及在 44.1/48/96 kHz、64/512 采样块下对所有工厂预设进行离线音频处理。构建和测试命令详见仓库 README。
