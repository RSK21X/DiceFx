# DiceFX 1.1.1 — DSP fixes / 音频处理修复

![DiceFX](https://raw.githubusercontent.com/RSK21X/DiceFx/v1.1.1/docs/images/dicefx-main.png)

## English

- Fixed unstable tone filters at low sample rates and preserved filter history during playback.
- Corrected stereo control changes, reverb timing and modulation across different host block sizes.
- Smoothed gain, mix and delay-time changes; fixed host resets and tail reporting.
- Fixed long tempo-synced delays at higher sample rates and removed audio-processing memory allocation.
- Kept the interface and parameter IDs unchanged; shortened both READMEs.

**Downloads:** universal macOS VST3 and standalone ZIPs, plus SHA-256 checksums. Quit your DAW and replace `DiceFX.vst3` in `~/Library/Audio/Plug-Ins/VST3/`. Standalone input starts muted.

Build target: macOS 11+, Apple Silicon + Intel. DSP and UI checks passed on macOS 27, natively and under Rosetta. Older macOS versions and a physical Intel Mac were not runtime-tested. Bundles are ad-hoc signed, not Apple-notarized.

The fixes may change sounds affected by the previous bugs. Regenerative Tape feedback can sustain indefinitely; choose an explicit export range when using it.

## 中文

- 修复低采样率音色滤波不稳定，保留播放过程中的滤波历史。
- 修正立体声控制变化、混响时间，以及不同宿主音频块长度下的调制行为。
- 平滑增益、混合和延迟时间变化，修复宿主重置及尾音声明。
- 修复高采样率下长节拍同步延迟被截短的问题，移除音频处理中的内存分配。
- 界面和参数 ID 不变；精简中英文 README。

**下载：**macOS 通用架构 VST3、独立应用压缩包和 SHA-256 校验值。退出 DAW 后，替换 `~/Library/Audio/Plug-Ins/VST3/` 中的 `DiceFX.vst3`。独立应用输入默认静音。

构建目标为 macOS 11+，包含 Apple Silicon 和 Intel。DSP 与界面检查已在 macOS 27 上通过原生及 Rosetta 运行；较旧的 macOS 和实体 Intel Mac 未经运行验证。发布包采用 ad-hoc 签名，未经过 Apple 公证。

修复旧错误后，受影响的声音可能改变。持续自激的 Tape 反馈可能无限延续，使用时请明确指定导出区间。
